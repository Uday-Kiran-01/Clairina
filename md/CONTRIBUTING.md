# Contributing

Thanks for taking an interest in contributing. Simple guidance:

- Create a feature branch: `git checkout -b feat/short-description`
- Run tests locally: `pytest -q`
- Keep changes focused and open a PR with a clear description

Code style
- Follow existing project style (PEP8); run `flake8` if available.

Testing
- Add unit tests under `tests/` for any new functionality.

Questions
- Open an issue describing the problem or desired enhancement.
