# Clairina

Lightweight marketing-mix modeling (MMM) utilities and a demo Streamlit app.

Author: Uday

Summary

This repository contains code and examples for regression-based MMM, simple
optimizer experiments, and a Streamlit demo to explore budget reallocations.
